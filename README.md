# AdventureWorks2025-SQL-Analysis
AdventureWorks2025 SQL Server project featuring SQL queries, database analysis, views, joins, aggregations, CTEs, subqueries, and window functions. Includes practical SQL tasks and solutions for Data Analyst portfolio development.

[Download AdventureWorks2025 Database](https://github.com/Sherumoddin/AdventureWorks2025-SQL-Analysis/releases/latest)

## How to Restore
1. Download the `.bak` file from Releases.
2. Open SQL Server Management Studio.
3. Right-click Databases and select Restore Database.
4. Select Device and browse for the downloaded backup.
5. Click OK to restore the database.
